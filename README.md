# Creeper Memory Moment

ابغاك تغير الصورة الي هنا الى هذه الصورة التي ارسلتها لك الان وتظهر عند الضغط على الكريبر تبقى 4 ثواني بعدها تنتقل بشكل تدريجي الى الاعلى بشكل ايقونة مثل الي في الملف أيضا ابغى زر رجوع في اعلى اليمين على شكل home يرجعك الى الشاشة الرئيسية أيضا ابغى الأغنية تشتغل اول ما اضغط على الكريبر وينفجر يشغل الأغنية وينقلك الى واجهة الصورة مباشرة ابغى الصورة مو تكون ملء الشاشة مرة ابغاها مثلا تكون ملء الشاشة بمقدار 85% فقط في المنتصف بعدها تتقلص حتى تصل الى اعلى اليسار إذا ضغطت على الصورة وهي على شكل ايقونة ترجع مرة أخرى لوضع ملىء الشاشة لكن بمقدار 40% في منتصف الشاشة بعد انتهاء الأغنية في حال لم يضغط زر الخروج يرجع الشخص مباشرة الى الشاشة الرئيسية
